# TASKONFF — скачать сайт

- [Скачать HTML-версию](./TASKONFF-HTML.zip?raw=true) — 40 страниц RU/EN, CSS, JavaScript, локальные шрифты и анимации.
- [Скачать исходный проект Next.js](./TASKONFF-source.zip?raw=true) — исходный код и серверные обработчики.

HTML-версия работает на обычном статическом хостинге. Для локального просмотра распакуйте архив и следуйте README-RU.txt; файлы запуска используют Python 3. В этой версии бриф создаётся в браузере без передачи данных серверу.

Исходный проект запускается через npm ci, npm run build, npm start. Зависимости, .git, результаты сборки и реальные .env-файлы в архивы не включены.

Контрольные суммы: [SHA256SUMS.txt](./SHA256SUMS.txt).

Эта ветка предназначена для передачи архивов. Основная ветка и опубликованная среда не изменялись.
